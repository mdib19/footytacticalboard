# footytacticalboard
This mini project combines my passion for IT and football. A simple tactical board for football coaches. <br>

## Demo:
https://mdib19.github.io/footytacticalboard/

## Features:
- Add and drag players freely <br>
- Undo actions <br>
- Clear the board <br>
- Save and load files (.json) <br>
